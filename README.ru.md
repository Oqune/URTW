# URT — Universal Routing Toolset

[English](README.md) | Русский

Терминальный центр управления для Windows: **Mihomo**, штатный менеджер
**Zapret** и **TG WS Proxy**. UI на Rust/Ratatui показывает реальные процессы,
локальные порты и результаты операций. Открытие приложения читает состояние;
подключение и изменение системного прокси включаются отдельными действиями.

![UI диагностики с демонстрационными результатами](docs/images/diagnostics.png)

*Демонстрационные данные; в рабочем режиме измерения запускаются пользователем.*

## Установка

1. Скачай ZIP своей архитектуры в [Releases](https://github.com/Oqune/URT/releases).
2. [Проверь GPG-подпись и SHA-256](docs/VERIFICATION.md), распакуй архив.
3. Открой `URT.exe`, вкладку **Components**, выбери компонент и нажми **I**.
   Загружается фиксированная версия с официального сайта; SHA-256 проверяется
   до установки. Установка не запускает компоненты.
4. Нажми **F**, выбери конфиг Mihomo `.yaml`/`.yml` или WireGuard `.conf`.
   **S** запускает Mihomo отдельно после выбора и проверки конфига.

Поддерживаются Windows 10/11 x64 и ARM64. **Zapret работает только на x64**.
Для запуска профиля с TUN и управления службами Zapret нужен терминал
администратора. В архиве нет персональных VPN-профилей и сторонних бинарников.
Для скачивания компонентов нужен работающий интернет: сначала установи и
проверь новый профиль, потом вручную переключай текущий VPN.

## Управление

| Вкладка | Возможности | Клавиши |
|---|---|---|
| Overview | Реальные состояния процессов, портов и Windows Proxy | F конфиг; S/X Mihomo; P системный прокси |
| Profiles | Выбор файла через окно Windows, список профилей, проверка | F файл; Enter выбор; S/X запуск/остановка |
| Diagnostics | HTTP-ответы, время запроса и фактический прогресс | D запуск; M путь; стрелки прокрутка |
| Telegram | Установка, запуск, порт, конфиг и ссылка подключения | I установка; S/X запуск/стоп; L ссылка; G Telegram; E порт; O конфиг |
| Zapret | Открытие оригинального `service.bat` | Enter менеджер; I установка |
| Components | Установленные и зафиксированные версии | Стрелки выбор; I/Enter установка |

**1–6 / F1–F6 / Tab** переключают вкладки. **Q/Esc** закрывает UI; службы
продолжают работать. Минимальный размер окна — **60×18**. Внешние процессы
помечаются **External** и не останавливаются по имени.

## Конфиги и два уровня маршрутизации

Выбор YAML сохраняет путь к исходному файлу и проверяет его через Mihomo,
не переписывая исходник. Требуется явно заданный `mixed-port`. Кэш и провайдеры
Mihomo используют приватную папку `mihomo-data`; внешние провайдеры YAML должны
иметь абсолютные пути или находиться там. Успешная проверка синтаксиса ещё не
подтверждает доступность VPN.

Импорт WireGuard поддерживает одного peer, IPv4 и дополнительный IPv6, DNS,
MTU, keepalive и preshared key. Исходный `.conf` сохраняется; создаётся отдельный
приватный YAML. Командные хуки и неизвестные директивы отклоняются.
По умолчанию **TUN выключен**, выбранные правила используют WG, остальное DIRECT.

Первый уровень — правила процессов и доменов Mihomo. Второй — отдельный
`browser-routing.pac`, выбирающий браузерные сайты по `browser-vpn-domains.txt`.
Для изменения стандартных списков скопируй `config/rules/` в приватную папку
`rules/` и импортируй профиль повторно. Правила приложений имеют приоритет над
доменами; DIRECT-домены идут раньше VPN-доменов. Существующий сгенерированный
YAML автоматически не меняется. Для глобального TUN включи `tun.enable: true`
в своём YAML и запускай профиль из терминала администратора.

[Настройка PAC в браузере](docs/BROWSER.md). В режиме **Mihomo inbound**
диагностика проверяет HTTP-прокси и его правила. Режим **System route** убирает
HTTP-прокси из тестового клиента, но может проходить через уже активный TUN.
403/429 — ответ сайта, а не доказательство неисправности маршрута. Прогресс
достигает 100% после завершения всех тестов, включая ошибки.

## Telegram

На вкладке Telegram нажми **I**, затем **S**. Запускается оригинальное tray-
приложение в portable-режиме с локальным адресом `127.0.0.1` и случайным
приватным secret. **L** копирует ссылку; **G** открывает окно подключения Telegram.
**E** меняет порт остановленного компонента; **O** открывает приватный конфиг.
Настройки DC, Cloudflare и WebSocket доступны в штатном меню трея.

Оригинальный TG WS Proxy допускает один экземпляр на пользователя Windows.
Уже работающий внешний экземпляр остаётся под управлением своего трея.
Подробности — [в инструкции Telegram](docs/TELEGRAM.md).

## Хранение и безопасность

Данные по умолчанию находятся в `%LOCALAPPDATA%\URT`: профили, настройки,
компоненты, логи и кэш. Пример явного выбора отдельной папки:

```powershell
URT.exe --root "D:\URT-data"
```

Новые приватные папки и файлы защищаются Windows ACL. URT не меняет метрики
адаптеров, настройки IDE, переменные прокси оболочки и посторонние службы.
Windows Proxy включается явно; его прежние значения сохраняются и восстанавливаются
только при подтверждённом владении. Остановка управляемого Mihomo сначала
восстанавливает включённый им системный прокси. Логи и профили не публикуются.

## Разработка и релизы

Rust **1.88+**, MSVC и Windows PowerShell 5.1. Сборка и проверки описаны
в [CONTRIBUTING.md](CONTRIBUTING.md). CI собирает x64 и ARM64.
Версия `v<ContractMajor>.<FeatureMinor>.<Patch>` закрепляет совместимость
контракта URT; правила основаны на Impulse, но версия его протокола не переносится
в этот независимый проект. Релизные заметки двуязычные, без эмодзи, с таблицей
архитектур. Подписанный тег запускает сборку draft-релиза; перед публикацией
его SHA-256-манифест подписывается локальным GPG-ключом.
