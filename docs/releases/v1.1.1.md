# URTW v1.1.1


## English

Windows companion to URTA: Mihomo, sing-box and Xray, private endpoint library,
custom ordered routing standards, browser PAC split and per-core DNS/options.
Ten responsive views, config picker/path input, portable folder choice, backups,
recovery, explicit autostart, native adapter extensions and upstream attribution.
Scoped process ownership and running-profile separation protect existing settings.

## Русский

Windows-компаньон URTA: Mihomo, sing-box и Xray, приватные эндпоинты, собственные
стандарты маршрутизации, сплит браузера и DNS/настройки каждого ядра.
Десять адаптивных вкладок, рабочий выбор файла, portable/выбор папки, бэкапы,
восстановление, явный автозапуск, адаптеры других ядер и указание авторов.
Текущие конфиги и процессы сохраняются отдельно от новых выбранных профилей.
