# URT v1.0.0

## English

First public release of Universal Routing Toolset for Windows.

- Responsive six-tab terminal UI with native configuration selection and real process status.
- Mihomo YAML validation and private single-peer WireGuard import; selective application/domain rules and separate browser PAC.
- Diagnostic progress counts all completed requests, including HTTP denials and transport failures.
- TG WS Proxy portable integration: install, start/stop, local port, private settings and Telegram connection link.
- Zapret opens its original `service.bat` manager.
- Pinned upstream downloads with SHA-256 verification; private runtime files stay outside source and release archives.
- Automated Windows builds, signed Git tag and detached GPG signature for the release checksum manifest.

## Русский

Первый публичный релиз Universal Routing Toolset для Windows.

- Адаптивный терминальный UI с шестью вкладками, выбором конфига через окно Windows и реальными состояниями процессов.
- Проверка YAML Mihomo, приватный импорт WireGuard с одним peer, правила приложений/доменов и отдельный PAC для браузера.
- Исправлен прогресс диагностики: учитываются все завершённые запросы, включая отказы сайтов и ошибки соединения.
- TG WS Proxy: установка, запуск/остановка, локальный порт, приватные настройки и ссылка подключения Telegram.
- Zapret открывает оригинальный менеджер `service.bat`.
- Фиксированные версии компонентов с проверкой SHA-256; личные профили и runtime-данные не входят в публикацию.
- Автосборка Windows, подписанный Git-тег и отдельная GPG-подпись манифеста контрольных сумм.
